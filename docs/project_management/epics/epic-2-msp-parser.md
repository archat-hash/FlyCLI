# Epic 2: MSP Protocol Parser

**Belongs to:** [Milestone 1.1.0](../milestones/m1.1.0-cli-foundation.md)

**Description:**
The application must correctly parse the MultiWii Serial Protocol (MSP) V1 and V2 headers, perform checksum validation, and handle timeouts (e.g. if the device doesn't respond to the handshake).
